# Продажи ЦО

Дашборд аналитики продаж Центрального округа на Streamlit.

## Возможности

- **📈 Динамика** — KPI, сравнение год к году (YoY), план/факт по кварталам,
  автоматические сигналы о снижении продаж, плитки по городам,
  иерархическая сводная таблица «дистрибьютор → город» с экспортом в Excel,
  редактор квартального плана.
- **🟧 ЭТМ** — выполнение плана и динамика по офисам продаж (ОП),
  разрезы по товарным категориям и специализациям, сравнение Север/Юг,
  автосигналы, выгрузка отчёта в Excel.
- **🟦 Русский Свет** — обзор с KPI и вкладом офисов / материалов в изменение продаж,
  месячная динамика и накопительный итог, выполнение плана и тепловая карта по офисам.
  В «По Офисам» для каждого города рядом показаны динамика и ТОП-10 материалов.
  Квартальный план филиалов загружается из Excel или редактируется в сессии,
  распределяется поровну на три месяца и хранится отдельно по годам;
  разбивка плана по материалам не задаётся.
- **🤝 Проектное взаимодействие**, **👥 Партнеры** — в разработке
  (см. Issues #3 и #4).

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

или через обёртку предпросмотра (нужен Node.js):

```bash
npm run dev
```

## Данные

Файлы загружаются через боковую панель «📂 Загрузка данных»:

| Источник | Формат | Используется во вкладках |
|---|---|---|
| Выгрузка продаж | `.xlsx`, лист `Table` | Динамика, Русский Свет |
| Выгрузка ЭТМ | `.xlsx`, листы «%ВП ГО DKC по спец/по ТГ» | ЭТМ |
| План Русского Света | `.xlsx`, лист «Планы РС», отдельные суммы четырёх кварталов; загрузка на вкладке «План» | Русский Свет |

Файлы обрабатываются только в памяти сессии и нигде не сохраняются.
Стартовый план по умолчанию читается из `data/plans.csv`
(генерируется утилитой `make_fake_plans.py`).

### Квартальные планы Русского Света

В боковой панели доступен отдельный блок «Фильтры Русского Света»: география, города/офисы,
материалы, годы сравнения и диапазон месяцев. Общие фильтры продаж на РС не влияют.
География соответствует ЭТМ: Север — Ярославль, Тверь, Владимир, Кострома,
Иваново; остальные города — Юг. Списки городов и материалов учитывают выбранную зону.
При смене географии выбираются все доступные города и материалы новой области;
годы сравнения и период сохраняются.

Во вкладке «Русский Свет → План» скачайте Excel-шаблон и заполните лист
«Планы РС»: `Филиал`, `Год`, `1 квартал`, `2 квартал`, `3 квартал`, `4 квартал`.
Одна строка — один филиал и год, у каждого квартала своя независимая сумма.
Пустой квартал считается нулевым планом. Филиал должен совпадать с названием города
в выгрузке продаж. Суммы указываются в рублях без НДС с точностью до копеек.
Формулы справа показывают все 12 месячных сумм; приложение читает только входные поля.
Прежний формат `Филиал`, `Год`, `Квартал`, `План_без_НДС` также поддерживается.

После загрузки первые два месяца квартала получают по 1/3 плана с округлением
до копеек, третий — остаток. Например, 100 руб. = 33,33 + 33,33 + 33,34 руб.
Месячный план используется в KPI, графиках и тепловой карте.
Файл загружается на вкладке «Русский Свет → План».
При сравнении за часть квартала учитываются только соответствующие месяцы.

Файл заменяет планы перечисленных в нём годов целиком: пропущенные филиалы
и кварталы этих годов получают нулевой план, другие годы сохраняются.
Повторяющиеся филиал/год/квартал, пустые обязательные поля и отрицательные суммы
не принимаются. Пользовательские планы остаются только в памяти сессии.

Шаблон в репозитории: `outputs/01a1e535-rs-plans/rs_quarterly_plan_template.xlsx`.

Парсер ЭТМ находит колонки по заголовкам («Январь 2026», «ГО план янв26»),
поэтому добавление новых месяцев в выгрузку не требует правки кода.
Годы анализа задаются константами `BASE_YEAR` / `CURR_YEAR` в `tabs/tab_etm.py`.

## Структура

```
app.py               — точка входа, боковая панель, стартовый экран
data_loader.py       — парсер выгрузки продаж
plans.py             — чтение/проверка плана продаж
make_fake_plans.py   — генератор тестового plans.csv
tabs/
  tab_dynamics.py    — вкладка «Динамика»
  tab_etm.py         — вкладка «ЭТМ»
  tab_rs.py          — вкладка «Русский Свет»
  tab_project.py     — заглушка «Проектное взаимодействие»
  tab_partners.py    — заглушка «Партнеры»
```
