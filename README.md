# Продажи ЦО

Дашборд аналитики продаж Центрального округа на Streamlit.

## Возможности

- **📈 Динамика** — KPI, сравнение год к году (YoY), план/факт по кварталам,
  автоматические сигналы о снижении продаж, плитки по городам,
  иерархическая сводная таблица «дистрибьютор → город» с экспортом в Excel,
  редактор квартального плана.
- **🟧 ЭТМ** — выполнение плана и динамика по офисам продаж (ОП),
  разрезы по товарным категориям и специализациям, сравнение Север/Юг,
  автосигналы, выгрузка отчёта в Excel.
- **🟦 Русский Свет** — продажи по филиалам, помесячная динамика по городам,
  ТОП-10 групп продукции, редактируемый месячный план с расчётом выполнения.
- **🤝 Проектное взаимодействие**, **👥 Партнеры** — в разработке
  (см. Issues #3 и #4).

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

или через обёртку предпросмотра (нужен Node.js):

```bash
npm run dev
```

## Данные

Файлы загружаются через боковую панель «📂 Загрузка данных»:

| Источник | Формат | Используется во вкладках |
|---|---|---|
| Выгрузка продаж | `.xlsx`, лист `Table` | Динамика, Русский Свет |
| Выгрузка ЭТМ | `.xlsx`, листы «%ВП ГО DKC по спец/по ТГ» | ЭТМ |
| План продаж | `.csv` (Год, Квартал, План_без_НДС) | Динамика |

Файлы обрабатываются только в памяти сессии и нигде не сохраняются.
Стартовый план по умолчанию читается из `data/plans.csv`
(генерируется утилитой `make_fake_plans.py`).

Парсер ЭТМ находит колонки по заголовкам («Январь 2026», «ГО план янв26»),
поэтому добавление новых месяцев в выгрузку не требует правки кода.
Годы анализа задаются константами `BASE_YEAR` / `CURR_YEAR` в `tabs/tab_etm.py`.

## Структура

```
app.py               — точка входа, боковая панель, стартовый экран
data_loader.py       — парсер выгрузки продаж
plans.py             — чтение/проверка плана продаж
make_fake_plans.py   — генератор тестового plans.csv
tabs/
  tab_dynamics.py    — вкладка «Динамика»
  tab_etm.py         — вкладка «ЭТМ»
  tab_rs.py          — вкладка «Русский Свет»
  tab_project.py     — заглушка «Проектное взаимодействие»
  tab_partners.py    — заглушка «Партнеры»
```
